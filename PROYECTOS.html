Proyectos

En esta sección se presentan los proyectos de investigación que se están llevando a cabo en el Semillero de Investigación con Inteligencia Artificial Aplicada (SIIA). Cada proyecto tiene como objetivo explorar y desarrollar soluciones innovadoras utilizando técnicas de inteligencia artificial para abordar problemas relevantes en diversas áreas.

Lista de proyectos:

1

Nombre del proyecto 1

Desarrollo de un sistema de recomendación basado en aprendizaje profundo para mejorar la experiencia del usuario en plataformas de comercio electrónico. Este proyecto busca implementar un modelo de red neuronal que pueda analizar el comportamiento de los usuarios y ofrecer recomendaciones personalizadas, aumentando así la satisfacción del cliente y las ventas.

2

Nombre del proyecto 2

Implementación de un modelo de procesamiento de lenguaje natural para la detección temprana de enfermedades a partir de registros médicos electrónicos.

3

Nombre del proyecto 3

Creación de un algoritmo de visión por computadora para la identificación automática de objetos en imágenes satelitales con aplicaciones en agricultura y medio ambiente.

4

Nombre del proyecto 4

Desarrollo de un sistema de reconocimiento de voz para la transcripción automática de reuniones virtuales.

5

Nombre del proyecto 5

Desarrollo de un sistema de recomendación para mejorar la experiencia del usuario en plataformas de e-commerce.
